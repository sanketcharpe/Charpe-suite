Signing in

Both tools carry their own sign-in, so out of the box the app asks you twice every time it opens. Save the two sets of details here and it will sign you in to both by itself.

What this means for security
With automatic sign-in on, anyone holding this phone unlocked can open your case list and your billing register. The password screens stop being a barrier — your phone's own lock becomes the only one. That is a reasonable trade on a phone you keep with you and a poor one on a phone left around chambers. These details are kept on this device only and are never included in a Drive sync or a backup file.

Setting up Drive sync

One-off, about five minutes. You only do this once, on any device.

1
In Google Drive make a folder for this — say Charpe Suite Data. Open it and copy the long ID from the address bar (everything after /folders/).
2
Go to script.google.com and start a new project. Delete whatever is in the editor and paste in the script from the file apps-script/Code.gs that came with this app.
3
At the top of that script, put your folder ID into FOLDER_ID and invent a long random password for SECRET. Save.
4
Press Deploy → New deployment, choose type Web app, set Execute as to Me and Who has access to Anyone. Authorise it when Google asks.
5
Copy the web app URL it gives you. Paste that URL and your secret into the Sync tab here, then tap Test.
Is "Anyone" safe?
"Anyone" only means Google won't ask for a Google login at the door. Every request still has to carry your secret, and the script refuses anything without it. The script is also written to touch only the one folder ID you gave it — it has no code path that can reach the rest of your Drive. Keep the secret private and treat the URL like a password.

Data & privacy

Where does my data live?
In this app's own storage on this device. Nothing is sent anywhere unless you set up sync, and then only to your own Drive folder. There is no server of mine in the middle.
What happens if I clear the browser data?
It would be erased, which is why sync and the export backup exist. Push to Drive after any session where you added real work.
